================================================================================================
命题 4 的实验出口：溢价是否可被"val 曲线噪声 × 极值尺度"预测
================================================================================================

  参与回归的 run：101 个（三分划 41 + 升格 40 + 同域 20）
  σ̂（val 曲线残差 sd，pp）：中位 0.445，四分位 [0.194, 0.656]
  溢价 premium_val（pp）：中位 0.769，四分位 [0.372, 1.096]

(P4-a) premium_val ~ a + b·σ̂  （预言：b > 0，且量级为 √(2 ln E) 的上界）
    n = 101  斜率 b = 0.026 ± 0.222（95% CI [-0.197, 0.248]）  截距 a = 0.768  r = 0.023  p = 0.818
    评测点数 E 中位 = 100 ⇒ 极值尺度 √(2 ln E) = 3.03（**上界**：相邻 epoch 高度相关，有效独立次数远小于 E）
    ⇒ **方向不符或未达显著，命题 4 的这一形式需要改写**
    相关比 b/σ̄ 的另一种读法：溢价中位 0.769 对应 σ̂ 中位 0.445（倍数 1.73）

(P4-b) 兑现率是否随 σ̂ 增大而**上升**（命题 4：兑现率 = 1 − WC/premium，WC 随噪声增大）
    有 test 侧读数的 run：81 个
    σ̂ 分位              n   prem_val  prem_test        兑现率
    0.121–0.289       27      0.644      0.423      65.6 %
    0.289–0.652       27      0.950      0.473      49.8 %
    0.652–2.028       27      0.801      0.111      13.8 %
    逐 run 的（prem_test/prem_val）与 σ̂：Spearman ρ = -0.466，p = 1.34e-05（n = 80）
    ⇒ **σ̂ 越大、兑现率越低**——与命题 4 的推论（兑现率 = 1 − WC/premium，WC 随噪声增大）**方向一致**
    说明：前一轮脚本在这里除了零（有 run 的 prem_val = 0），报出 NaN 并误判为"方向相反"，已修。
