### 本文用到的术语（集中一处，读者不必再从上下文反推）

| 术语 | 在本文里的含义 |
|---|---|
| **臂（arm）** | 配对比较的一方：**基线**臂遵循已发布约定，**策略**臂是受检干预（例如改变峰值学习率）。"基线"**不是**"未改动的软件"——两臂跑同一套代码 |
| **格（cell）** | 设计中的（语料对 × 臂）单位。格名如 `shwd2sf` 读作**源→目标**（SHWD → SFCHD）；语料为 `dota15`、`aitod`、`visdrone`、`smoke`、`shwd`、`sfchd`、`mende`、`mask` |
| **`best` / `last`** | 全文比较的两个 checkpoint：训练脚本按**适应度**在被监控划分上写出的 `best.pt`，与末轮 |
| **选择溢价** | 同一 run 内的 `best − last`：选最优点位带来的增量，就在数字上报的那条划分上量 |
| **Δgap** | 两臂溢价的**配对差**，按语料给出；为正表示 `val` **低估**策略臂效应（§5.1 Tier 2） |
| **兑现率** | `prem_test / prem_val` 的聚合（§8.6）：在 `val` 上选出的溢价有多少在独立 `test` 上兑现 |
| **κ** | 逐 epoch 的 `ΔT` 对 `ΔV` 的过原点斜率（§8.7）：一个 run 在 `val` 上的移动有多少出现在 `test` 上 |
| **同目录 / 别名** | 数据集配置把 `val:` 与 `test:` 指向同一路径，于是 checkpoint 就在被上报的划分上选出 |
| **`shapeiou`** | 注册复现策略臂所用的形状感知 IoU（§9） |
| **`sio_b_results.csv`** | 干净协议批次的逐 run 结果表；其端点口径未成文，已作为缺陷披露（§10） |
| **FROZEN-HASH** | 注册的自指戳：**戳行之上**那段文本的 md5 摘要（§9，任何人可重算复核） |
